# Engineering Large Language Models - Public Edition, September 2026

**[Download the free PDF](https://github.com/ykirpichev/llm-book/releases/download/public-2026-09/engineering-large-language-models.pdf)** · **[Read online](https://github.com/ykirpichev/llm-book/blob/public-2026-09/manuscript/00_front_matter.md)** · **[Download source](https://github.com/ykirpichev/llm-book/releases/download/public-2026-09/engineering-large-language-models-source.zip)**

A free technical book by Yury Kirpichev covering the path from model foundations
and training to inference, accelerators, distributed execution, production
applications, and technical leadership. Seventy chapters across nine parts
include worked examples, original diagrams, CPU teaching references, and a
capstone. The research cutoff is September 13, 2026.

## Read and reuse

Download `engineering-large-language-models.pdf` to read offline. The source
archive includes the editable manuscript, figure and PDF builders, runnable
examples, tests, and build instructions. `SHA256SUMS` verifies the release assets.
Use Python 3.12 and Poppler; run `make verify` to test and rebuild.

Book text and original figures use CC BY 4.0. Original code uses MIT. Both allow
free reuse, including commercial reuse, under the terms in LICENSE, LICENSE-BOOK,
and LICENSE-CODE. Third-party works retain their own terms.

## Review and limitations

This edition was developed with AI-assisted writing, technical review, and
editing, including Astra, Sol, and Terra review passes. It has not received
independent human technical review or professional copy editing. The current
release-readiness record describes the executable and visual checks performed.

CPU references are tested. Accelerator code remains source-only here: no
hardware compilation, device execution, real serving-engine benchmark, or
frontier training reproduction is claimed. Published research results retain
their cited scope; teaching examples are not production guarantees.

Corrections and reproducible improvements are welcome through GitHub Issues
